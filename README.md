# SmartURL

SmartURL is a small Flask application for creating short links and generating QR codes. Short-link records are stored in SQLite. QR images are generated by the app with the local `qrcode` Python package; the QR workflow does not use a third-party QR API.

## Requirements

- Python 3.10 or newer
- Windows PowerShell, Command Prompt, macOS, or Linux terminal

## Run locally

From the project folder, create and activate a virtual environment, then install the dependencies:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

On macOS or Linux, activate the environment with:

```sh
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Start the development server:

```sh
python app.py
```

Open the local address printed in the terminal, usually `http://127.0.0.1:5000`.

## How links work

The `/api/shorten` endpoint stores the destination and returns a short URL. When someone opens that short URL, Flask looks up its code and redirects to the saved destination. The `/qr-code` endpoint creates a PNG in memory and returns it to the page.

Local short links only work while the local Flask server is running, and are reachable only from your computer. To share links publicly, deploy the Flask app to a public host and create the links using that public address. A production deployment also needs persistent storage for `smarturl.db`, or a hosted database, so links survive restarts. Do not use Flask's built-in development server for production traffic.

## Project files

- `app.py` - Flask routes, short-link redirects, and QR generation
- `index.html` - Page structure and forms
- `script.js` - Form submission, status feedback, copying, and QR downloads
- `style.css` - Responsive layout and visual styles
- `requirements.txt` - Python dependencies
